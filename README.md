## Projetos

### Machine Learning
[ml-knn-syndrome-classification](https://github.com/eriiksa/ml-knn-syndrome-classification) : classificação de 10 síndromes via embeddings de imagem (941 sujeitos). KNN cosine e euclidiana avaliados com StratifiedGroupKFold 10-fold, com métricas implementadas em NumPy. Melhor F1 macro 0,76.

### Dados e ETL
[EstagioIntuitiveCare](https://github.com/eriiksa/EstagioIntuitiveCare) : ETL e API em Python para organizar e expor dados de despesas do Governo a partir de CSV.

### Automação e RPA
[Auto_doc](https://github.com/eriiksa/Auto_doc) : aplicativo desktop em Python criado na FedEx para resolver um gargalo real, a busca manual de CTEs (documentos de transporte) em três sistemas diferentes. A partir de uma lista de números de documento, o app acessa Enfase, LMS e Tivit com Selenium, baixa os CTEs encontrados e renomeia cada arquivo pelo número da NF, usando OCR do Tesseract para ler os PDFs. Interface em Tkinter, credenciais guardadas no Keyring e distribuição como .exe via PyInstaller.

[Amazon-Selenium-Automation](https://github.com/eriiksa/Amazon-Selenium-Automation) : robô em Python com Selenium que navega pela Amazon, adiciona itens ao carrinho e valida o carrinho.
